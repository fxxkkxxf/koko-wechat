# 0.4.0 发布说明

2026-10-31 完成源码整合，并在用户明确授权后重启本机后台。实际运行版本已通过后台接口确认为0.4.0，不能仅凭源码版本判断是否升级。

## 发布内容

- 一批短句共用一次微信前台会话，逐条核对后恢复一次窗口。
- 公共事实查询由应用实际联网取得来源，天气使用独立数据接口。
- 原生图片输入接通微信图片读取链路，群聊图片和问题按成员隔离。
- 控制台按原消息显示对应回复及逐条发送状态。
- 修复天气迟到错误回写、发送前取消，以及旧监听器迟到图片的竞态。
- 启动器显示实际后台版本；源码版本单独显示，版本不一致时明确提示需要重启。

## 验证与升级

- 发布前Node全量183项通过（含新增4项启动器版本测试）。
- Python全量93项：92通过、1因Windows符号链接权限跳过。
- 模拟界面96项检查通过；独立公开HTTP查询、合成图原生识图和模型检索请求均验证通过。
- 升级前备份账号设置和发送记录；升级后核对模型、人设、联网开关及会话选择。
- 一条历史发送未知记录已保留未知状态并标记跳过，不补发旧回复；受影响群聊已恢复。没有发送测试消息。

## 桌面交付约定

后续每次发布同步更新“可可微信助手.lnk”和“可可微信助手_最新版.zip”，保留固定名称。快捷方式使用项目正式目录和应用图标，压缩包排除个人配置、聊天、密钥缓存和运行数据。更新前备份旧交付件，完成后回读版本和文件哈希。具体执行规则见项目AGENTS.md。

本次升级后的检查证明后台已加载新版并恢复监听；尚未通过主动发送真实微信消息做收发测试。锁屏、微信界面变化、图片缓存不足或外部服务限流仍可能导致操作失败，结果不明确时不会自动重发。
