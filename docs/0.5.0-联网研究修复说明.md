# 0.5.0 联网研究修复说明

## 问题与处理

旧流程把口语句子送给一次搜索，再让模型基于摘要回答，缺少打开网页和继续核实的步骤。实际还发现搜索源会把多词查询降成单字词典结果，相关性筛选又会误删有效结果。仅在提示词里写“主动联网”不能解决这些问题。

本版让聊天模型先理解当前公开话题、补全主体、选择查询词，再交给独立研究流程。研究模型返回结构化计划，应用执行真实搜索或读取网页，结果再交回模型决定下一步。最多4次行动、整体90秒上限；普通常识不强制搜索。Bing RSS没有相关结果时尝试公开中文备用源，检索与页面错误反馈给研究流程，允许换关键词或来源。

当前已登录Codex客户端的真实探测中，即使开启相关设置也没有观察到原生web_search调用。结构化计划模式已用真实模型验证并作为生产默认；可选的动态工具模式仅完成模拟测试，未作为本版生产默认。此实现不宣称与ChatGPT聊天栏搜索完全相同。

## 页面与来源

网页读取验证公开HTTP(S)地址、DNS解析与每次重定向，不访问本地或私有网络、不提交登录信息；限制大小、时间及跳转数。仅提取公开文本，不执行网页脚本或其中的指令。来源区分“搜索摘要”和“已读正文”。模型即使声称查到，没有实际来源也不能被标记成功。

管理页展示本次查询词、规划、搜索、读取正文进度和具体错误。新的失败会清除上一条成功结果，避免把旧来源误认为本轮证据。正文无法读取、只有摘要或资料不支持所问细节时，应明确说明核实边界。

## 隔离与现有功能

公开研究仅收到提炼的公开问题、本轮公开来源、日期及时区，不收到微信历史、人设、长期记忆、摘要或图片。主聊天仍可理解有限会话上下文以提取主体。明显账号ID、手机号、邮箱、凭证等在查询边界清理或拒绝；这不是对任意私人叙述的完整自动匿名化保证。

保留独立天气HTTP数据源、按成员隔离的地理上下文、清空后的迟到请求保护、图片原生输入、短句批量发送、已选参与会话、主人设定和发送核对记录。测试不发送真实微信消息。

## 实际验收

- 一般提问“健怡可乐是什么样的”：正常解释Diet Coke及口味区别，没有为了稳定常识额外搜索。
- 明确要求核对可口可乐官网：实际搜索并读取 `https://www.coca-cola.com/us/en/brands/diet-coke` 正文，回答Diet Coke与无糖信息并给出官网来源。该次总耗时约54秒。
- 《三角洲行动》撤离点玩法：实际补全游戏和玩法关键词并多次改词；初次验收中攻略正文未能取得，最终区分摘要、已有知识推断与未核实的具体打法，没有冒充完成查证。小众玩法仍可能需要地图、版本等更具体信息。
- 继续排查确认3DM评论登录框被误当正文门禁，现已修正。最终实测读取牧羊人攻略第6页及第3页公开正文，回答陷阱和手雷配合时给出两页实际来源，并区分原文内容、归纳打法及2025年旧攻略的版本限制；该次研究约37秒。
- 东莞明天天气：实际通过Open-Meteo取得所需日期预报，来源、日期与地点一致，约6秒。

真实验收运行在独立目录和独立客户端，未访问生产会话，微信发送数为0。最终Node测试241/241通过；Python测试108项（107通过，1项Windows符号链接能力相关跳过）；模拟管理页126/126通过且无JS错误。覆盖搜索、网页安全、取消与预算、迟到模型切换、主流程、天气竞态和管理页。来源检查不接受本轮未取得的网址；引用缺失或虚构时退回真实资料摘要，不把无关真来源自动贴给编造的结论。

## 使用限制

多轮查询会比直接回答慢，也会多次使用当前已选模型。网络步骤上限不是固定完成时间保证，首次连接或主聊天归纳还会增加耗时。网站可能需要登录、限制抓取或只返回JS空壳，公开搜索也可能过时或搜不到；不会绕过这些限制。用户可以在管理页看见正在执行的步骤与失败原因。停止或清空会取消本轮研究，迟到结果不能恢复旧查询状态。
