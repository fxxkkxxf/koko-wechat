# 0.7.0 群聊主动搭话

## 怎么用

1. 在「参与会话」中选择需要接入的群，应用选择。
2. 到「群聊与主动搭话」找到该群，点击「开启主动搭话」。
3. 确认该群的群开关、顶部自动回复总开关已开启。保存规则不会擅自打开已暂停的群或总开关。
4. 点击「编辑」可以调节主动搭话间隔与每小时上限。关闭主动搭话后恢复原来的被 @ 或点名接话规则。

本功能只由选定群的新消息触发。可可根据当前话题补充信息、自然接梗，或回应面向全群的问题。安静时不自行开话题，不主动私聊。新接入的群默认仍按点名接话，升级沿用原有模式。

## 如何决定参与

- 同一波消息短暂合并，同一群只保留一个主动判断；模型收到每条发言对应的成员身份及本群最近上下文。
- 纯表情、单独的图片占位、很短的附和先旁听。每次主动判断至少间隔20秒。一次判断仍在进行时，其他普通群消息不会产生并行的主动判断。
- 提示词要求只有能补充内容或自然接话时才加入；别人一对一聊天、背景不足时可以返回不回复。明确 @ 别人时不主动插话。群友明确换话题时取消尚未发送的旧主动判断；过时超过60秒的结果不发送。
- 被 @、叫名字的直接请求会优先于尚未发送的主动判断。加入后同一成员在接话窗口继续聊，按照原来的普通回复规则处理。
- 使用现有群聊公开角色和本群上下文；私聊与其他群的资料不进入本群输入。多人合并的主动判断不保存个人长期事实，避免把甲的话记到乙名下。

## 频率

默认每群主动搭话至少间隔120秒，每个滚动一小时最多3轮。可调整范围：间隔30—3600秒，上限1—20轮。

这些是主动插话限制，普通点名回复另有原来的回复冷却。一次主动回复无论分成几个短句都算一轮；真正发起发送前持久保存次数，结果不明或部分送达也算一轮，避免重启后重复搭话。只判断后选择旁听不消耗发言次数，但会调用模型。频率记录按账号和群分别保存，保留有限条目，不随启停或重新勾选群聊而重置。

## 后台显示和发送

最近活动会标明「主动搭话」，关联触发的原消息、旁听/限流原因、生成的文字与发送结果。模型可以不回复；判断理由是规则状态或模型选择旁听，不展示模型内部推理。

继续使用现有后台文字、短句批量发送、账号核验、发送前账本与发送后本机记录确认。失败不自动改用前台，不重发结果不明的消息。公开资料的来源链接在后台模式下同行追加，避免仅因来源分行而触发多行输入限制。原有多行正文与特殊emoji的兼容限制仍见0.6.1说明。

## 验证边界

使用隔离的模拟群聊与浏览器管理页验证主动判断、多人身份、直接请求优先、频率、重启保留、取消、未知发送和配置保存；没有向真实微信联系人或群发送测试消息。是否插话是模型判断，实际话题相关性仍需使用中观察，可按群关闭或调整频率。
